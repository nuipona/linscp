LinuxSCP Commander ✕

Sessions opens the site manager: stored sessions are shared with the console client, and each tab keeps its own connection open.

Transfers run in the queue at the bottom. They can be paused, cancelled and retried; a cancelled transfer does not disturb the session.

Synchronize compares the two panes and shows the plan before it changes anything. "Both" uses the record of the previous synchronization to tell a change from a conflict.

Edit (F4) opens a remote file in the built-in editor and uploads it when you save; it refuses to overwrite a file that changed on the server while you were editing it.

Keys: F4 edit, F5 upload, F6 download, F7 new folder, F8 delete, F9 synchronize, F10 refresh, Ctrl+A select all, Enter open, Backspace up.

The CLI tab runs commands in the live session of the current tab.
