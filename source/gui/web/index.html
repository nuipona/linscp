LinSCP Commander ✕

Sessions opens the site manager: stored sessions are shared with the console client, and each tab keeps its own connection open.

Transfers run in the queue at the bottom. They can be paused, cancelled and retried; a cancelled transfer does not disturb the session. You can also drop individual files from your desktop onto the remote pane to upload them.

Synchronize compares the two panes and shows the plan before it changes anything. "Both" uses the record of the previous synchronization to tell a change from a conflict.

View (F3) opens a selected text file read-only. Edit (F4) opens a local or remote text file in the built-in editor. Saving checks that the file has not changed since it was opened; remote edits upload to the server.

Commander keys: F1 help, F2 rename, F3 view, F4 edit, F5 copy to the other panel, F6 move files to the other panel, F7 new directory, F8 delete, F9 properties/rights, F10 close session. Ctrl+A selects all; Enter opens a directory; Backspace goes up one level. Move is available for files; folders can still be copied, but are not moved by the cross-panel move action.

The LinSCP command console runs commands in the live session of the current tab.
