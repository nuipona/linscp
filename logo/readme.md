# LinSCP logo

The mark is a fairy penguin - *Eudyptula minor*, the smallest penguin, whose
feathers are slate blue - with a blue arrow arriving from the left (downloads)
and a green arrow leaving to the right (uploads).

## Files

| File | What it is |
| --- | --- |
| `linuxscp-mark-source.png` | 1600x1600 master artwork on flat white. Keep it as the pristine source. |
| `linuxscp-mark.png` | Master mark, background removed, full width. Used by `../readme.md`. |
| `linuxscp-mark-compact.png` | Penguin with simplified solid arrows, for 32-64px sizes. |
| `linuxscp-mark-symbol.png` | Penguin only, for 16-24px sizes. |
| `linuxscp-badge.png`, `linuxscp-symbol.png` | Rounded-tile compositions at 1024px. |
| `linuxscp-logo.png` | Horizontal lock-up: badge plus wordmark. |
